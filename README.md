# AI Career Coach

An AI-powered career guidance platform that helps students analyze their resumes, identify skill gaps, receive career recommendations, and prepare for technical interviews.

## Features

### Resume Analysis

* Upload resumes in PDF format
* Extract and analyze resume content
* Generate resume scores and feedback
* Identify strengths and improvement areas

### Career Recommendations

* Suggest suitable career paths based on skills and experience
* Provide personalized career guidance

### Mock Interview

* Generate role-based interview questions
* Multiple difficulty levels (Easy, Medium, Hard)
* Practice technical and behavioral interviews

### Analytics Dashboard

* Visualize performance metrics
* Track progress over time
* View interview and resume analysis insights

### Authentication

* User Registration
* Secure Login System
* User Dashboard

## Installation

### Clone Repository

```bash
git clone https://github.com/katramanamounika/ai-career-coach
cd ai-career-coach
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

### Resume Analyzer Setup

```bash
cd backend/resume-analyzer
pip install -r requirements.txt
python -m uvicorn main:app --reload
```
